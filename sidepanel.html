Clé API Mistral

Saisissez votre clé API Mistral.

Pour celles et ceux qui ont un compte Mistral Vibe, cette clé est habituellement accessible à l'url suivante : https://chat.mistral.ai/code/extensions Cliquez sur « Avancé », puis copiez la clé API Vibe. Cela consommera dans les limites fournies par votre abonnement, qu'il soit gratuit ou Pro, sans frais supplémentaire.

Il est aussi possible de générer une autre clé API, mais cela pourrait vous générer des frais proportionnels à votre utilisation ; pour cette raison il vaut mieux utiliser la clé API Vibe fournie avec votre abonnement.

La clé est stockée localement dans votre navigateur (chrome.storage) et n'est jamais inscrite en dur ni envoyée ailleurs que vers l'API Mistral.
